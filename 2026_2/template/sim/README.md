# Simulación

Las pruebas deben ser automáticas y reproducibles. Cada prueba debe indicar:

- módulo o comportamiento verificado;
- estímulos aplicados;
- resultado esperado;
- criterio explícito de aprobación o fallo;
- archivo de formas de onda cuando sea necesario.

El ejemplo `test_blink.py` verifica el núcleo funcional del periférico `blink` sin requerir una plataforma FPGA.
