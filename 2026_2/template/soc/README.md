# SoC LiteX

Este directorio contiene la construcción principal del SoC. La entrega debe identificar claramente:

- plataforma y FPGA utilizadas;
- procesador femtoRV32;
- regiones de memoria;
- periféricos y bancos CSR;
- interfaz de red;
- ruta DMA;
- señales conectadas a LiteScope;
- proceso de construcción y programación.

El archivo principal del SoC debe permitir generar nuevamente el diseño sin depender de archivos producidos manualmente dentro de `build/`.
