# Interfaz de red

La red debe cumplir una función dentro del proyecto final. Documentar:

1. interfaz física y bloque LiteX utilizados;
2. conexión con el bus del SoC;
3. mapa de memoria o CSR asociados;
4. formato de los datos transmitidos y recibidos;
5. función de la red dentro del juego;
6. prueba reproducible de transmisión y recepción;
7. señales verificadas mediante simulación o LiteScope.

No se considera completa una interfaz que solamente genere enlace físico sin intercambio verificable de datos.
