# LiteScope

Utilizar LiteScope para observar el sistema ejecutándose en FPGA. La configuración debe incluir señales relacionadas con:

- ejecución de instrucciones de femtoRV32;
- acceso a memoria o CSR;
- transferencia DMA;
- transmisión o recepción por red.

Entregar:

1. código que instancia `LiteScopeAnalyzer`;
2. lista de señales y profundidad de captura;
3. condición de disparo;
4. archivo de captura;
5. interpretación técnica de las señales observadas.

No se deben incluir señales sin explicar qué comportamiento permiten verificar.
