# Firmware

Este directorio contiene el firmware del juego, los drivers de periféricos y las pruebas de integración.

La entrega debe permitir identificar:

- código de arranque y `main()`;
- mapa de memoria utilizado por el software;
- acceso a CSR;
- configuración de la interfaz de red;
- configuración y ejecución del DMA;
- programas mínimos usados para estudiar instrucciones;
- procedimiento de compilación y carga en el SoC.
